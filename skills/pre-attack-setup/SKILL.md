# 攻擊前 setup 分類(收斂 / 多頭拉回)

> **載入時機**:分析「這檔的 setup 是收斂還是多頭拉回」「發動前特徵」「大漲前的 setup 籤名」「觀察股 / 重點觀察篩選」「處置股發動點怎麼定」時。

## 核心目的(防 drift — 先讀這段)

收斂與多頭拉回是**所有股票都會出現的 setup**,不是處置股特有。分類器的目的是**預測大漲**,不是分類處置股本身:

```
收斂 / 多頭拉回 setup(持續許多 K 棒)
      ↓ 分類型
 進入觀察股 + queue 對應分K策略(兩型策略不同)
      ↓ 攻擊(發動K)出現
 重點觀察 + 啟動分K策略 → 預測大漲
```

- **setup 階段**(收斂/多頭拉回辨識完成)→ 進**觀察股**,並依分類型 queue 對應分K策略
- **攻擊出現** → 升**重點觀察**,啟動該型分K策略

**為什麼分類的「型」重要**:收斂型和多頭拉回型套**不同的分K策略** — 分類是「選哪支下游策略」的路由,不是終點。

> ⚠️ **範圍剎車**:這是 **watchlist 產生器 + 策略路由**,不是交易 edge / 完整策略。下游才接分K策略。禁止 drift 成策略最佳化或「找 heuristic」。

## 處置股 = 大漲正樣本的免費收割源(切入點,非 domain)

交易所的**處置機制 = 免費的大漲股篩選器**:大漲才會被處置,所以處置股 = 保證大漲過的股票。從處置股切入 = 不必自己掃全市場找大漲股,**省下採樣成本,直接拿標準答案**。

- 處置股是**標註工具 / 切入點**,不是 domain 本身
- 從處置股的發動K往回萃取 setup = 學「大漲前的 setup 籤名」(乾淨 positive labels)
- 分類器學成 → 套用**全市場所有股票**(不限處置股)→ watchlist

## 兩型對稱心智模型(分類骨架)

兩型用**不同長度的均線**辨識(收斂看長、多頭拉回看短) — 這是對稱設計的核心,不是任意選特徵。背後解釋(**推論,非 user 原話**):收斂是長期均線聚攏壓縮、多頭拉回是多頭格局中短均線的拉回行為,故對應不同均線長度:

| 型 | 物理機制 | 主辨識均線 | 動作 |
|----|---------|-----------|------|
| **收斂** | 長期均線聚攏壓縮 → 突破噴出 | **長均線聚攏度**(ma5/6 sqz %,含至 260MA) | 壓縮末爆量 |
| **多頭拉回** | 多頭格局中短均線糾結拉回 → 止穩再發動 | **短均線**(ma3/2 sqz %) | 測 25/65/130 MA 任一止穩 |

- **收斂看長均線**:壓縮是長期均線聚攏,看短均線會誤判(短均線糾結 ≠ 長期壓縮)。包含兩變體:全均線收斂 / 5MA 收斂(站上 260MA)。
- **多頭拉回看短均線**:多頭格局下長均線必然發散(看 ma5 沒意義),拉回是短均線的行為。
- **多頭拉回測多 MA**:不是每檔都測 25MA — 25/65/130 **任一**都可能是支撐(案例:某檔測 130MA)。規則要支援多 MA 支撐,不是硬綁 25MA。
- **V 轉歸「其他」**:V 轉不好切入,先丟其他,不硬分兩型。

> 對稱設計的理由(收斂=長、拉回=短)在 code 已落實,但 code 不會說**為什麼**。改規則時先問「這型別的對應均線長度」,別用錯長度。

## 邊界案例判讀(初步觀察,待更多案例驗證)

> 以下來自 50 檔 golden 的 dogfood(skill 套用在訓練資料上 84%、L6 override 挽回 5/10 — 10 = 全部 L6 override 案含 2「其他」;只算收斂/多頭 8 案為 5/8)+ 動態特徵 probe。**小樣本觀察,套新標的須重新驗證**(同「判讀陷阱 1」精神 — 別把這些當普世規則硬套)。

- **ma5/ma6 背離**(ma5 小壓縮但 ma6 大發散):用衍生特徵 `diverge_65`(= ma6_min − ma5_min)**量化背離** — 真收斂壓縮 diverge 小、多頭發散 diverge 大(全量 golden 區分乾淨,classify 目前未用 ma6_min)。收斂認定以 ma5 為主(ma6 大可能是更早期發散殘留)。⚠️ **但背離帶(diverge 大)收斂/多頭會擠一起,沒有乾淨 tie-breaker**(vol_end_vs_min 試過:多頭案例卻高 vol 的反例存在)→ 最硬 case 是 **C 層,L6 看圖**,特徵救不了。
- **空頭格局(b260 ≤ 0)**:兩型都假設非空頭。b260≤0 → 預設「其他」,不硬分。(案例:1568 b260=-5.8)
- **「其他」要主動觸發**:V 轉 / 空頭反彈 / 派發頂部 / 特徵游離無主導訊號 → 都歸其他。skill 易漏判「其他」(dogfood 中 4 個 golden「其他」一個都沒抓到 — 這是最普遍的盲區)。
- **dist 汙染特徵語義**:dist≥15(尤 =20 上限)會把早期波動平均進 setup 窗,使 ma_min 偏大似發散。dist 大時用動態特徵(width_min / wyckoff_end)交叉驗證,別只看靜態 ma_min。(案例:2454、3545 dist=20)
- **短均線「糾結」質化判準**:ma3 > 4~5 通常已不糾結(用全量分位校準)。多頭拉回要 ma3 真的糾結才算,ma3 偏大又無明確發散 → 可能是「其他」。(案例:3545 ma3=6.1 不糾結)
- **兩型特徵同時成立**(全均線壓縮 + 多頭格局 + 測25MA):主從 — 全均線壓縮(收斂)優先,除非有明確發散的長均線(才轉多頭拉回)。(案例:6155)

## 發動點定位(find_anchor 哲學)

> 此處 anchor = **發動K(起漲那根大漲K)**,非 [broker-flow-analysis](../broker-flow-analysis/SKILL.md) 的價位 anchor。

處置是「前面大漲」的**果**;發動K(攻擊)通常落在處置生效前數根。定位發動點的關鍵判讀:

- **真發動 ≠ 最近的大漲K**:最近的大漲K可能是「再次攻擊」(已發動後的追擊),不是起漲點。
- **真發動 = 大漲後 low 不破到處置**:該大漲K的低點,在它之後到處置生效前**都沒被跌破**(趨勢有效,大漲成立)。從最早(離處置遠)往近找,第一個 low 守住的就是發動點。
- **不能太早**:搜尋有上限(~20 根);更早的大漲是無關事件,非本次起漲。
- **發動點離處置的距離**:原則是「大漲低點不破 + 不能太早」(搜尋上限 ~20 根)。實測多落在處置前 10+ 根(非固定 5-7 根 — user 早期看法 5-7,後修正「要更往前」;「10+ 根」是實測 dist 統計,非 user 給的數字)。

> 現行實作:`find_anchor`(poc/sqz/key_candle_anchor.py,POC → 未來進 mosaic domain)。機械部分交 code;**「這是真的發動點還是再次攻擊」「dist 太短是否 vacuous-true 邊界」是 LLM 判讀**,尤其 dist≤2 的邊界案例要 L6 看圖拍板。

## 反模式(流程層 — 不要這樣做)

> 通用研究紀律(別發明特徵 / 別四分法 / 別 boolean OR)見 [golden-sample-research](../golden-sample-research/SKILL.md)。此處只列本 domain 特有:

1. **用錯均線長度判型** — 收斂用短均線、多頭拉回用長均線 → 兩型誤判混血。先認定物理機制再選均線。
2. **多頭拉回硬綁 25MA** — 支撐可能是 25/65/130 任一。只測 25MA 會漏掉測長 MA 的多頭拉回。
3. **把處置股當 domain** — 處置股是採樣工具,目的是全市場大漲預測。研究框架不能釘死在處置股。
4. **drift 成交易 edge** — 「找 heuristic / 最佳化報酬」是下游策略的事。本分類只負責 setup 型別 + watchlist 路由。

## 判讀陷阱(數字層)

1. **小樣本誤導** — 曾從 2 檔推論「support_test_n 收斂=0 / 多頭拉回≥1」,被全量推翻(support_test_n med=2、b25_cross_neg med=1,兩型皆然)。**2-3 檔的推論必須全量驗證**才能寫進規則。
2. **in-sample 100% ≠ 一般化** — 全 golden 對齊-validator 的 100% 是 heuristic + 少數 L6 修正的結果,不是 out-of-sample。下游 LGBM 正式化需 time-respecting split。
3. **減資股 260MA 假高** — 減資使 260MA 被撐大,b260 偏高假象。個別容差(調門檻讓它過),不為單檔增複雜度(處理減資很麻煩)。
4. **主辨識是靜態三特徵** — `ma5_min`(收斂度)/ `b260`(格局)/ `b25_min`(拉回深度)。**動態特徵實驗中(user 明確:還沒仔細看怎麼用)**:全量驗證下多數動態特徵(ma5_low_days / width / wyckoff)兩型 median 不區分;**但 `vol_end_vs_min` 是 in-sample 驗證的收斂指紋**(收斂 4.8 vs 多頭 2.3 — 壓縮後爆量比更大;尚未 out-of-sample)。動態特徵當 **tie-breaker** 可挽回部分 static 分錯的案例(見下「邊界案例判讀」),但不宜當主分辨。user 曾(mid-session)假說動態特徵比 b25_min 準,該假說的 `support_test_n`/`b25_cross_neg` 部分被全量推翻(兩型 med 皆 2/1,不區分)。

## 校準:golden 是活的

- **LLM 是分類建議者,不是裁決者**:agent 每檔提案 → 主 session 統整 → **人類 L6 看圖拍板**。golden set 允許 `L6_OVERRIDE`(改型別)/ `L6_EXCLUDE`(剔除 — 如極端異常股)。
- **規則迭代是常態**:收斂用「條件式門檻」(ma5 分段決定是否加查 ma3/ma4),非 boolean OR。門檻數值從 golden 觀察極值調,不用四分法推估。
- **缺 out-of-sample loop(未閉合)**:目前只驗證「處置股 setup 分得對」,沒驗證「全市場套用後預測的大漲真的發生」。分類器要能在非處置股上預測出會大漲的,才算達成核心目的。

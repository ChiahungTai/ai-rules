# 券商分點進出分析(BSR)

> **載入時機**:分析個股「盤底接手、誰在買/賣、主力進出、集中度、價位帶買盤、造市 vs 方向 vs grid」時。
> **資料源 = 台股盤後 BSR**(券商分點進出):每支股票當日每個分點(broker branch)在各價位的買進/賣出股數彙總。**粒度 = 券商 × 價位,非逐筆** → 看不見掛單主動性、放空 vs 現股、tick 微觀。與價量 TA(`trading-analysis` skill)是不同資料軸。

## 核心紀律:先找 focal point,反散槍

分點分析最常見的失敗 = **沒有 focal point 的廣度掃描**(散槍):能算的維度都算、AI 自選整數價位帶、產出固定三分法讓用戶逐一訂正。

**正確起手**:先找/問**一個結構性關鍵價位**(當日最低點 / 某分點發動點 / 開盤急殺段底 / 壓力突破點),以它為 anchor 萃取買賣盤,**證明**該價位買方吃掉特定賣壓 → 造成後手行為。**一個 anchor、一條因果鏈,勝過九區塊全掃。**

## 盤底/反轉接手 playbook(6 步)

> 針對「先手接手 → 後手發動」**兩段式反轉結構**(盤底 / 吸籌 / 反轉)。單階段結構(純造市 / 隔日沖 / 純 grid)不走此 playbook,用下方「角色診斷透鏡」。

1. **建立價位 context + 識別 anchor** — 日K 定位當日 low/open/close;**1 分K 結構化找 anchor(非猜),並確認 anchor 對應可解釋的盤中區段**(急殺後反轉 / 突破回踩,非圖表假象)。底部 anchor 識別法之一:**長下影線**是視覺 cue(先手吸籌足跡);結構定義 = 1 分K **N字 L-H-L**(上→回→上,且**低點抬高** l2>l1)→ anchor = **h1 = 第一個 N字的左邊高點**(後續 N 突破的 level);第二個 N字若貼近則兩個一起考量,取 cluster 最左高點(即第一個 N 的左高)。**第一個 N字最關鍵(案例觀察,待驗證)**。anchor = 「先手接手 ↔ 後手發動」**相位邊界**(接手↔發動 兩階段轉換點;接 step 5)。此為底部識別法之一,非唯一。
2. **依價位帶 filter,按分點 group** — 目標帶 = `[當日低點, anchor]`,算每分點 buy/sell/net,net 降序,**買方 top-N 與賣方 top-N 都列**。polars:`df.filter((pl.col("price")>=day_low)&(pl.col("price")<=anchor)).group_by("broker_code").agg(...)`,net=buy−sell,集中度=買量÷當日成交量。⚠️ **分倉**:若懷疑同集團多分點分倉,group 前按集團合計(broker_name 前綴 split),否則單分點低估主力。
3. **對比買方結構 vs 賣方結構** — 接手**集中**(單一大戶)或**分散**(一群中實戶 each +十幾張合力)?算該帶總淨:>0 = 買方蓋過賣壓。
4. **交叉每個買方的多日累計庫存曲線** — 建議回溯 ≥20 交易日(系統 BSR 通常只近期,**長期庫存曲線需外部歷史**);分類:連續單向累積(留倉)/ 當日來回(平倉)/ 長期斜率≈0 → 區分「先手底座」vs「後手投機」+ 判造市/方向/grid(見下)。
5. **驗證「穩住 → 後手」因果鏈(僅兩段式結構)** — 證明後手(發動者)在**更高價位帶**操作、盤底確立後才進場。先手創造條件,後手才敢發動。若無兩段式結構,跳過此步。
6. **避陷阱 + 校準**(見下;單一個案 ≠ 通則)。

## 角色診斷透鏡(單分點 — 獨立於 playbook,適用任何情境)

| 透鏡 | 主要證據 | 交叉驗證 |
|------|---------|---------|
| 造市 vs 方向 vs grid | 多日累計庫存曲線**形狀**(平坦貼零 vs 大波段單向) | grid 另加:對稱度 + bid-ask 價差能否 cover 當沖稅 |
| 接手(先手) vs 發動(後手)(僅兩段式) | 先手在最低檔吃賣壓;後手在更高帶拉抬 | 多日累計 + 進場時序 |
| 集中 vs 分散接手 | 單一大戶 vs 一群中實戰合力 | — |

- **對稱度** = 同分點買賣絕對量接近度(per broker;1.0 = 完全對稱兩邊掛,低 = 單邊方向)。grid 核心對稱度高、方向邊界下降(**案例觀察,非普世閾值**)。
- **長期零庫存(淨累計≈0)與「造市 / grid 當沖 / 經紀客戶集合」都一致** —— 單憑此**不足以**定論「是造市者」;需曲線形狀 + 價差能否 cover 稅 + 是否留倉交叉驗證。
- **放空判讀 caveat**:BSR 無融券/借券標記,「放空」是行為推斷(低賣高買、留倉為正=回補>放空),**非鐵證**。
- **台股造市制度**:僅簽約造市者(低流動性股/TDR/ETF)免稅;高流動性普通股對稱掛單是 grid/低接高出當沖(付當沖證交稅 0.15%),**無 maker rebate**(異於美股)。

## 反模式(流程層 — 不要這樣做)

與下方「判讀陷阱」(**讀數字**的錯)區別,這裡是**分析流程**的錯:

1. **散槍 / 無 anchor 廣度掃描** — 能算的維度都算、AI 自選整數價位帶。先找一個結構 anchor 再分析。
2. **全日淨買超 ↔ 價位結構混用** — 把全日淨買超當價位結構判讀 → 把高檔追價誤判成低接。淨買超必須拆到價位帶才算數。
3. **硬三分法** — 預設「低接/當沖/倒貨」分類框硬套 → 解套誤判倒貨、追價誤判低接。讓證據(價位+多日+集中度)決定角色,不預設框。
4. **查承銷商找主力** — 承銷業務帳戶 ≠ 主力炒作帳戶。查承銷商找不到主力;看「大買賣日 × 公司事件時間點」。
5. **LLM 摘要當證據** — WebSearch/外部摘要會腦補。外部宣稱要原文連結(公開觀測站/公開說明書)。

## 判讀陷阱(數字層)

1. **平均掩蓋階段** — 後續報酬不可跨趨勢期平均(多頭/空頭/盤整混合)。分階段 + 逐一個案。
2. **末值陷阱** — 累計末值掩蓋波段(末值小負,曲線可能先大正再大負)。看曲線形狀。
3. **淨超被造市抵消** — 兩邊大量掛、淨≈0。看絕對量 + 集中度。
4. **配對利潤幻覺** — BSR 無逐筆,段內/FIFO/整體配對互相矛盾。用淨現金流 + 庫存市值(留倉是資產)。

## ⚠️ 校準:單一個案 ≠ 通則

本 skill 提煹自**單一盤底案例**。任何「signature / 指紋 / 範本」(分散接集中賣壓、長期零庫存、高對稱度 grid 核心、**以及「先手穩住 → 後手發動」playbook 本身**)都是**該案觀察**,套用新標的時須重新驗證,不可當普世規則硬套 —— 這正是「判讀陷阱 1(平均掩蓋階段)」的同一精神:**個案差異 > 概括**。

## 個案指標(完整敘事在 project doc)

源案例:一檔股票盤前利空殺到日低,用戶錨定「後手發動點」這個關鍵價位,萃取其下買盤 → **分散式中實戰合力吃掉少數大戶的集中賣壓(割肉 + 放空 + 追殺)穩住底部 → 後手在更高帶進場拉抬**;另有一分點長期零庫存但含方向性大單,最終判讀為「非純造市、有方向判斷」。完整方法 + 陷阱 + 全敘事見 mosaic 專案 `ai-analysis/analysis/daytrade-bsr-analysis.md`(該處的「6 方法」是廣度分析,本 skill 的「6 步 playbook」是 focal-point 紀律精煉,兩者不同)。**程式 verdict**(anchor / dispersion / absorption / band_net,Code-computes)見 mosaic `mosaic_alpha/broker_flow_analysis/` 模組 + CLI `scripts/research/analyze_focal_point.py`;本 skill 補 LLM 判讀層(step 5 因果 / 角色邊界 / 敘事)。

使用统计
使用统计用来查看 ZCode 的实际使用情况。它分为 应用用量 和 编程套餐 两个部分：前者统计本地 ZCode 会话，后者读取 Z.ai / BigModel Coding Plan 的远端额度与消耗。
应用用量
应用用量 统计当前设备上的 ZCode 会话记录，适合回看自己最近在 ZCode 里完成了多少任务。
你可以看到：
Token 用量、会话数、消息数和活跃天数。
当前连续使用天数、最长连续使用天数和峰值时段。
按天 Token 趋势、活跃热力图和模型用量排行。
按天 Token 趋势图支持悬停查看每日各模型的用量明细；下方的模型用量环图则汇总各模型的 Token 占比，方便确认主力模型的实际消耗分布。
右上角可以切换 全部时间、最近 30 天、最近 7 天，用于快速对比近期使用情况。
编程套餐
编程套餐 读取 Z.ai / BigModel Coding Plan 的远端统计，适合查看套餐额度、模型消耗和工具调用情况。下图以 Z.ai - Coding Plan 为例；如果你使用的是 BigModel - Coding Plan，同样可以在这里查看对应的额度和消耗。
这里会展示：
5 小时 prompt 池、每周额度、MCP 每月额度等套餐状态。
GLM-5.3、GLM-5.3-Flash 等模型的 Token 消耗。
联网搜索 MCP、网页读取 MCP 等工具调用次数。
点击或展开额度信息时，还可以查看当前上下文窗口的组成、消息和工具调用占比，以及 5 小时、每周、工具调用等剩余额度。
额度重置卡
5 小时额度或每周额度用完后，不一定要干等下一个周期。ZCode 3.8.1 及以上版本会在端内显示当前可用的 5 小时 / 每周额度重置机会：有重置机会时，直接在端内点击即可重置对应额度。GLM Coding Plan 其他活动发放的重置卡也会在端内一并显示，使用方式相同。
注意：重置卡只会下发给登录 ZCode 并连接了当前账号 Coding Plan 的用户。如果没有登录账号、只用 API Key 接入，或者登录的账号没有开通 Coding Plan（即使配置了 API Key），都不会收到重置卡。
使用统计的 编程套餐 页同样会显示可用的重置按钮，以及累计获得的重置次数：
点击「重置」后，对应额度会立即恢复到 100%，并在卡片上标记「已重置」：
ZCode 会在 闲时 自动向 Coding Plan 用户下发 5 小时额度重置卡，需要同时满足三个条件：当前处于闲时时段、5 小时用量超过阈值、当日下发次数未达上限。注意重置卡的闲时时段与闲时任务的闲时范围不是同一套；具体时段和用量阈值都是动态调整的参数，以端内实际显示为准。下发后，输入框右下角会出现重置额度的提示：
重置卡有 有效期，必须在有效期内使用，过期自动失效。点击重置按钮会弹出「可重置额度」面板，其中会列出每张卡的过期时间；有多张时，会自动使用最早获得的那张。
